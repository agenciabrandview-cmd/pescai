# pescAÍ — Atendimento com IA

Plataforma de atendimento e vendas pelo WhatsApp com IA.

## Estrutura
- `index.html` — app completo (HTML, CSS e JavaScript num arquivo só).

## Como rodar
Abra o `index.html` no navegador. Também pode publicar de graça no **GitHub Pages**:
Settings → Pages → Branch `main` / pasta `root` → Save.

## Observação
Esta versão é o front-end (protótipo). Os dados ficam salvos no navegador (`localStorage`).
Para clientes reais se cadastrarem e usarem, ainda é preciso um back-end
(login, banco de dados, integração com a API do WhatsApp e com a IA).
